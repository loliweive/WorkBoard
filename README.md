# WorkBoard

个人任务看板 + 设备流转台账，基于 Flask + 原生 JS，数据本地存储，支持桌面窗口运行。

---

## 环境要求

- Python 3.10+
- 依赖库：

```bash
pip install flask pywebview
```

---

## 启动方式

**桌面模式**（独立窗口，支持透明悬浮）：
```
双击 任务看板启动.bat
```

**浏览器模式**：
```
双击 启动.bat
```
然后访问 `http://localhost:8765`

---

## 功能介绍

### 任务看板
- 三列看板：**待办 → 进行中 → 已完成**
- 勾选任务复选框自动推进状态；拖拽卡片可跨列移动
- 支持子任务（勾完自动升级父任务状态）
- 支持标签、截止日期、关联文件夹、笔记（含图片粘贴）

### 优先级
- 主任务和子任务各自独立设置优先级（高 / 中 / 低）
- 列内自动按优先级排序；点击卡片上的优先级标签可直接切换

### 设备流转台账
- 侧边栏底部"📦 设备管理"
- 登记设备（名称 + 编号），默认在库
- 记录借出（借走人 + 自动日期）、归还，保留完整流转历史
- 可将退役设备划线标记

### 月度工作总结
- Header 右侧"📄 本月总结"，可选择任意月份生成
- 自动统计当月完成任务、标签分布、进行中/待办列表
- 输出 Markdown 文件至 `data/monthly/`

### 其他
- 侧边栏日历标记截止任务、节假日
- 法定假日 + 自定义倒计时（颜色编码）
- 全局搜索（标题、说明、标签、文件夹）
- Header 右侧"？"查看使用说明

## 任务结构建议

| 条目特征 | 建议放在 |
|---------|---------|
| 方向 / 领域，无法直接"去做" | 标签 |
| 有明确交付物，需多步骤 | 主任务 |
| 能在一次工作中完成的具体动作 | 子任务 |

> 如果子任务还需要再拆，说明主任务粒度太大——拆成多个主任务，而不是往下加层。

---

## 数据文件

```
data/
  tasks.json        # 任务数据
  devices.json      # 设备流转记录
  countdowns.json   # 自定义倒计时
  notes/<id>.json   # 任务笔记（含图片，已在 .gitignore 中排除）
  monthly/          # 月度总结 Markdown
```
